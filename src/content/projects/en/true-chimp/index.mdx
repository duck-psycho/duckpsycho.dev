I decided to put my own spin on the Chimp Test from <Link href="https://humanbenchmark.com/tests/chimp" external>Human Benchmark</Link>.

It's the classic Chimp Test, with the option to set a time limit for memorizing the numbers.
Results and personal bests are saved without requiring registration (an account is created automatically).

I really like the idea of automatically creating UUID-based accounts. No username or password,
just save your UUID and you're all set. Neither this project nor <Link href="https://reader.duckpsycho.dev/" external>Telegram Reader</Link>
stores sensitive data, so this approach is a perfect fit.

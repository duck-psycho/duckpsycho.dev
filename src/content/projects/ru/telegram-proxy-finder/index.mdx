Приложение с очень простой идеей и реализацией. Загружаются публичные списки прокси(из GitHub-репозиториев,
которые регулярно обновляются), а потом каждый прокси проверяется через `tdlib` на доступность и пинг.

Для работы нужна только сеть, приложение собирает списки с бесплатными прокси и выбирает именно те,
которые работают на вашем устройстве и у вашего провайдера. Из-за этого в прокси может быть спонсорский канал, тут уж как повезет.
Потом нажимаете "Connect" на любом из них, и все.

### Добавлено 05.07.2026

GitHub: https://github.com/duck-psycho/telegram-proxy-finder/releases/tag/v1.2

В версии 1.2 следующие изменения:
1. Источники из Telegram-каналов. Теперь прокси также загружаются из Telegram-каналов через Finder API(не напрямую из Telegram),
в дополнение к уже существующим спискам из GitHub.
2. Автоматическая проверка обновлений через GitHub Releases.
3. Ускоренная загрузка источников. Списки прокси теперь загружаются параллельно, а не по очереди, благодаря чему поиск запускается быстрее.
4. Сокращенные тайм-ауты сети. Тайм-ауты подключения и чтения по HTTP уменьшены (до 5 и 10 секунд соответственно).
Теперь поиск по источникам из кэша будет начинаться быстрее, если у вас проблемы с доступом к githubusercontent.com

Небольшое кроссплатформенное приложение, написанное на `Rust`, которое решает простую, но насущную проблему для пользователей `Claude Code`:
отсутствие удобного способа следить за расходом лимита использования. Приложение показывает процент использования текущей 5-часовой сессии прямо на иконке в
системном трее, а при наведении или клике показывает одну и ту же разбивку по использованию — как по 5-часовому окну, так и по недельному лимиту (7 дней).

Технически оно работает довольно просто: вместо того чтобы требовать отдельной авторизации, приложение считывает OAuth-токен,
который `Claude Code CLI` уже хранит локально в `~/.claude/.credentials.json`, и
обращается к тому же API использования, которым пользуется сам клиент.

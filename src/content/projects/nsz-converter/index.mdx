Моя первая попытка погрузиться в мир Nintendo Switch, но без разработки под Horizon.
Разбирался с NSZ и проверял <Link href="https://cursor.com/" external>Cursor</Link> с моделью Composer.
Достаточно элегантное решение для пользователя получилось, еще и размер последней версии 1.23 МБ.

NSZ Converter конвертирует файлы Nintendo Switch из сжатого формата NSZ в NSP без использования `prod.keys`.

Приложение бесплатное и без рекламы, но его исходный код закрыт, потому что я не хочу, чтобы кто-либо паразитировал на нём или выложил в Google Play.

Единственное разрешение, необходимое для работы, — это доступ к записи в выбранную директорию.
Приложение не собирает никаких данных и не имеет доступа к сети(из-за добавления проверки обновлений в версии 1.2 теперь имеет,
но использует только для загрузки https://github.com/duck-psycho/nsz-converter/releases).

### Добавлено 05.07.2026

GitHub: https://github.com/duck-psycho/nsz-converter/releases/tag/v1.2

В версии 1.2 следующие изменения:
1. Возможность конвертировать папку целиком, вложенные папки также учитываются.
2. Во время конвертации файлов больше не нужно каждый раз предоставлять разрешение для выходной папки. Выбранный путь теперь сохраняется.
3. Новая тема, вдохновленная дизайном Nintendo Switch.
4. Автоматическая проверка обновлений через GitHub Releases.
5. Сообщение о поддержке разработчика больше не показывается при первом запуске и каждом 5-м последующем.
